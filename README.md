# 🌐 Personal Portfolio Website

A responsive and modern personal portfolio website built to showcase my projects, skills, and experience. The portfolio highlights my work in web development and provides easy access to my projects, resume, and contact information.

---

## 🚀 Features

### 👤 Personal Branding

* 👋 Introduction section with name and role
* 🧾 About section describing skills and goals
* 📄 Resume download option

### 💼 Projects Showcase

* 📂 Display of multiple projects with descriptions
* 🔗 Live demo links for each project
* 🐙 GitHub repository links
* 🎯 Highlighted projects like:

  * Expense Tracker (Firebase)
  * AI Component Generator
  * Task Management App
  * Weather App
  * Currency Converter
  * Password Generator

### 🛠️ Skills Section

* ⚡ Technical skills (HTML, CSS, JavaScript, React, Node.js, Java)
* 📊 Visual progress indicators
* 🎯 Professional skills (problem solving, teamwork, etc.)

### 📜 Certificates Section

* 📄 List of certifications with external links

### 📬 Contact Section

* 📩 Contact form (Formspree integration)
* 🔗 Social media links (GitHub, LinkedIn, Instagram)

### 🎨 UI/UX Features

* 📱 Fully responsive design
* 🎯 Smooth navigation with active section highlighting
* ⚡ Clean and modern UI
* 🎨 Icon integration (Font Awesome, Boxicons)

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Tailwind CSS
* Formspree (for contact form)

---

## 💻 Installation & Setup

### 1. Clone the repository

git clone https://github.com/rachitgupta05/portfolio.git

cd portfolio

### 2. Open in browser

Just open `index.html` in your browser
